# FrequencyAndNeurons

**What sets gamma frequency: the neurons' own time constants, or how many phase slots the computation needs?**

The claim under test (from a Gemini conversation) was that the separation between phase slots sets the frequency, T ≥ N × (slot + reset), so that needing two ~12 ms slots makes 40 Hz. The mainstream view is the reverse: the excitation–inhibition loop's time constants set the period, and slots are whatever fits inside it.

This repo builds an emergent PING gamma network, with **no pacemaker**. Excitatory leaky integrate-and-fire (LIF) cells drive fast-spiking basket cells, which inhibit them back through GABA_A synapses. It then sweeps both sides of the question.

Run `python fan.py` (about 2 minutes, numpy only), then `python make_figure.py`. Frequency is measured from the basket-cell volley intervals (median). The spectral peak is used only as an oscillation-quality check, because it sometimes locks onto harmonics.

| **S4: the "slot": when in the cycle E cells actually fire** (shortest arc holding 80% of E spikes) | The period grows **3.6×** (18 → 65 ms), but the window grows only **1.8×** (1.9 → 3.4 ms), shrinking from 11% to 5% of the cycle |

## Reading it

1. **Frequency comes from the loop's physics.**
   - Slower inhibition gives a slower rhythm, linearly in period.
   - More drive gives a faster rhythm.
   - This is what Whittington & Traub found pharmacologically (GABA_A modulators shift gamma frequency) and what Ray & Maunsell found with stimulus contrast.
2. **Slot demand does nothing by itself.** Asking the network to carry 16 independent streams instead of 1, at the same total drive, leaves the frequency where it is. Nothing in the circuit senses how many slots are needed. A demand-driven frequency would require an extra mechanism that measures load, which the plain E–I loop doesn't have.
3. **The window isn't a slot that the period is built from.** The period stretches with inhibition decay, but the firing window stays at 2–3 ms. The window is set by how fast E cells escape inhibition together, which depends on membrane and synaptic kinetics. So in this circuit, slower inhibition buys *more dead time per cycle*, not wider slots.
4. **It matches the uploaded paper, not the Gemini numbers.** Drebitz et al. found V4 gamma at about 73.5 Hz (a 13.6 ms period) with an effective input window of about ±45°, roughly 3.4 ms. The windows are a few milliseconds, as here, not the 10–12 ms slots the T ≥ N × (slot + reset) story needs.

## Where the "demand" direction could still be true

- **The slow rhythm, not gamma.** In theta–gamma coding (Lisman & Idiart 1995; Lisman & Jensen 2013), capacity is the ratio of the two periods. Axmacher et al. (2010) found that higher working-memory load went with *slower* theta in human hippocampus. That is load stretching a cycle, which the plain loop here cannot do.
- **The test that would show it:** add a slow, load-sensing variable (for example, adaptation driven by how many assemblies are active) that lengthens the theta-scale cycle. Then check whether the number of gamma cycles per theta cycle tracks the number of items. That is a new mechanism, and this repo shows it is *needed*: the gamma loop alone doesn't provide it.

## Ledger

- **Mean-field all-to-all coupling.** There is no spatial structure, no E→E recurrence, and no I→I synapses (this is pure PING; ING and mixed regimes can behave differently).
- **The single-ping admission curve is noisy.** It uses 10 phase bins and about 50 pings per bin (the `ping_curve` field). The window claim rests on the E-firing arc, which is model-free and uses every spike.
- **The frequency range (16–53 Hz) reflects these parameters.** The scaling laws are the result, not the absolute numbers.
- **This settles the question for a PING gamma only.** It says nothing about theta, or about gamma generated by other mechanisms.
